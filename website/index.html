Install

Python (full CLI + REST API + HuggingFace sync)

git clone https://github.com/vamshinr/ModelFit.git
cd ModelFit
python3 -m venv .venv && source .venv/bin/activate   # required on Debian/Ubuntu (PEP 668)
pip install -e .
modelfit wizard

Requires Python 3.9+. Only deps: rich + psutil.

macOS native binary (arm64, ~200 KB)

curl -LO https://github.com/vamshinr/ModelFit/releases/download/v0.1.0/modelfit-0.1.0-macos-arm64.tar.gz
tar xzf modelfit-0.1.0-macos-arm64.tar.gz
cd modelfit-0.1.0-macos-arm64
xattr -d com.apple.quarantine modelfit-cli modelfit-gui    # clear Gatekeeper
./modelfit-cli rank --top 5

Apple Silicon only for now. Linux + Intel macOS + Windows builds coming.

The five commands you'll actually use

modelfit wizard — for total beginners

Two questions, one recommended model, one install command. ~2 minutes from zero to chatting locally.

modelfit — show everything that fits

modelfit                  # default: balanced
modelfit -u chat          # leaning toward speed
modelfit -u code          # for writing code
modelfit -u reasoning     # for hard problems

modelfit recommend — give me ONE pick

Picks the best balanced choice, explains why in 3 sentences, gives Ollama / LM Studio / llama.cpp install commands.

modelfit get <model>

Copy-paste install commands for Ollama, HuggingFace + llama.cpp, and LM Studio, plus download size.

modelfit explain <term>

109-entry glossary across 10 categories: basics, hardware, quantization, training, architecture, inference, engines, applications, safety, theory.

How "fits" is decided

A model fits when, after picking a quality level (compression) and a context length, total memory needed is less than what your computer has. ModelFit:

  • Tries the highest quality first, walks down (Q8_0 → Q6_K → Q5_K_M → Q4_K_M → Q3_K_M → Q2_K) only if needed.
  • Tries the full context first, walks down (100% → 50% → 25%) only if needed.
  • Picks the highest-quality combo that fits.
  • Leaves 8% memory headroom so your machine doesn't choke on the first long prompt.

The catalog is 206 hand-curated entries plus anything synced from HuggingFace (modelfit catalog sync). Curated quality scores always win on duplicates.
